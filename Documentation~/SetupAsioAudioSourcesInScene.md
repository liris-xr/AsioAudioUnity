## Setup ASIO Audio Sources In Scene

If you have an existing scene and you want to add ASIO Audio Sources, you will need the [AsioAudioSource](/Documentation~/Audio%20Components/AsioAudioSource.md) component.

### Creating a new ASIO Audio Source

To add a [AsioAudioSource](/Documentation~/Audio%20Components/AsioAudioSource.md) component on scene, you can go multiple ways:

1. Use prefab: A prefab named `ASIO Audio Source` is present on the `Packages` folder, at `Packages/Asio Audio Unity/Runtime/Prefabs/ASIO Audio Source.prefab`, you can simply drag and drop this prefab on scene.
2. Setup GameObject: You can add a GameObject with an [AsioAudioSource](/Documentation~/Audio%20Components/AsioAudioSource.md) component on scene by going to *GameObject > AsioAudioUnity > ASIO Audio Source*.

For the [AsioAudioSource](/Documentation~/Audio%20Components/AsioAudioSource.md) component properties, go to the [AsioAudioSource Properties Setup](/Documentation~/Audio%20Components/AsioAudioSource.md#properties-setup) section.

**To setup OSC for your ASIO Audio Sources, refer to [Setup OSC Environment](/Documentation~/SetupOscEnvironment.md).**
